# Credits and provenance

GhostPath was rebranded from a historical Linux privacy shell project.
Legacy script comments acknowledge Hiroshiman, ParrotSec, cysec666 and
others. The existing code and commits are preserved in legacy-v1.

The distribution license for the legacy scripts is not yet confirmed.
Those scripts must not be repackaged into a new stable distribution
without provenance/licensing review. New Python modules in develop-v2
are authored separately and contain no legacy script copies.
